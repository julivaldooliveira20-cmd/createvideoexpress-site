Política de Privacidade — Create Video Express

Última atualização: 23 de novembro de 2026

1. Sobre o aplicativo

O Create Video Express é um aplicativo de desktop de uso pessoal/interno que produz e publica vídeos nos canais do próprio usuário. Não é um serviço comercial para terceiros.

2. Dados que acessamos

Mediante autorização explícita do usuário (OAuth do Google), o aplicativo acessa:

  • Identidade básica do canal do YouTube conectado (nome e ID do canal);
  • Playlists e lista de vídeos do próprio canal;
  • Estatísticas de visualizações e receita do próprio canal (YouTube Analytics);
  • Permissão para enviar vídeos, thumbnails e legendas ao próprio canal.

3. Como usamos os dados

  • Publicar vídeos produzidos pelo usuário em seu próprio canal, com metadados definidos por ele;
  • Exibir estatísticas do canal dentro do aplicativo;
  • Organizar vídeos em playlists do próprio canal, quando solicitado.

Nenhum dado é vendido, compartilhado ou usado para publicidade.

4. Armazenamento

Tokens de acesso ficam armazenados localmente no computador do usuário, criptografados (Windows DPAPI). Quando o usuário usa o serviço de publicação agendada (worker próprio no Cloudflare), os tokens ficam cifrados em banco privado (AES-GCM) acessível apenas pelo operador. Não há banco de dados de usuários nem coleta de dados pessoais de terceiros.

5. Revogação

O usuário pode desconectar um canal dentro do aplicativo ou revogar o acesso a qualquer momento em myaccount.google.com/permissions. Ao revogar, o aplicativo perde o acesso imediatamente.

6. APIs utilizadas

O aplicativo utiliza a YouTube Data API v3 e a YouTube Analytics API, em conformidade com os Termos de Serviço das APIs do YouTube e a Política de Privacidade do Google.

7. Contato

Dúvidas sobre esta política podem ser enviadas pelo canal de suporte do aplicativo.
