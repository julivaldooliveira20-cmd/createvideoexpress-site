Política de Privacidade — Create Video Express

Última atualização: 23 de novembro de 2026

1. Sobre este documento e o aplicativo

Esta Política de Privacidade descreve como o Create Video Express, aplicativo de desktop desenvolvido e operado por Julivaldo Oliveira, coleta, usa, armazena e protege dados quando o usuário conecta sua conta Google/YouTube. O aplicativo é de uso pessoal/interno: não é um serviço comercial para terceiros e não possui cadastro de usuários externos.

2. Dados que acessamos

Mediante autorização explícita do usuário via OAuth 2.0 do Google, o aplicativo acessa somente os dados do canal autorizado:

  • Identidade do canal — nome e ID do canal do YouTube conectado (escopo youtube.readonly);
  • Playlists e vídeos — lista de playlists e vídeos do próprio canal, para organizar publicações (escopo youtube.readonly);
  • Estatísticas — relatórios de visualizações, tempo de exibição e receita do próprio canal (escopos yt-analytics.readonly e yt-analytics-monetary.readonly);
  • Permissão de publicação — enviar vídeos, thumbnails e legendas ao próprio canal (escopos youtube.upload e youtubepartner).

O aplicativo não coleta dados pessoais de terceiros, não acessa contatos, e-mail, localização, histórico de navegação ou qualquer dado fora dos escopos listados.

3. Como usamos os dados

Os dados acessados são usados exclusivamente para:

  • Publicar no canal do usuário os vídeos que ele próprio produziu no aplicativo, com título, descrição, tags, thumbnail, legendas e visibilidade definidos por ele, em datas por ele agendadas;
  • Exibir, dentro do aplicativo, o nome do canal conectado, playlists e estatísticas do próprio canal;
  • Manter o funcionamento das publicações agendadas enquanto a conexão estiver ativa.

Nenhum dado é vendido, alugado, compartilhado com terceiros ou usado para publicidade, marketing ou perfilamento. Não transferimos dados do usuário para nenhum serviço externo além das próprias APIs do Google/YouTube e da infraestrutura privada do operador descrita abaixo.

4. Onde os dados são armazenados

  • No computador do usuário: os tokens de acesso OAuth e configurações ficam armazenados localmente, criptografados com a API de proteção de dados do sistema operacional (Windows DPAPI);
  • No serviço de agendamento do operador: quando o usuário usa a publicação agendada em nuvem, os tokens são cifrados (AES-256-GCM) e guardados em banco de dados privado (Cloudflare D1) acessível somente pelo operador; os arquivos de vídeo ficam em armazenamento privado (Cloudflare R2) pelo período necessário à publicação.

Não mantemos banco de dados de usuários, nem servidores de coleta de dados pessoais.

5. Retenção e exclusão

  • Os tokens ficam armazenados enquanto a conexão estiver ativa;
  • O usuário pode desconectar um canal dentro do aplicativo, o que apaga o token local, ou revogar o acesso em myaccount.google.com/permissions — a revogação interrompe o acesso imediatamente;
  • Vídeos armazenados temporariamente para publicação agendada são excluídos após o envio ou dentro do prazo de retenção configurado pelo operador.

6. Segurança

Os segredos são protegidos por criptografia em repouso (DPAPI no desktop; AES-256-GCM na nuvem privada), as comunicações ocorrem exclusivamente por HTTPS, e o serviço de agendamento exige token de autenticação próprio em todas as operações.

7. APIs do Google e serviços do YouTube

O aplicativo utiliza a YouTube Data API v3 e a YouTube Analytics API em conformidade com os Termos de Serviço das APIs do Google, os Termos dos Serviços de API do YouTube e a Política de Privacidade do Google. O aplicativo não gera imagens com IA e não produz conteúdo íntimo não consensual.

8. Crianças

O aplicativo não é direcionado a crianças e não coleta intencionalmente dados de menores de idade.

9. Alterações nesta política

Atualizações desta política serão publicadas nesta mesma página, com a data de revisão atualizada no topo.

10. Contato

Dúvidas sobre privacidade e proteção de dados podem ser enviadas pelo canal de suporte do aplicativo.
